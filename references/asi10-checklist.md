# OWASP ASI-10 Agent 安全风险清单（LLM/Agent 应用领域参考）

来源：OWASP Top 10 for Large Language Model Applications（公开标准，2025 版 ASI-10）。
用途：审查 LLM/Agent 应用时代码/配置的安全维度。对每个元素逐条对照，命中即标记。

## 风险清单

| # | 风险 | 说明 | 审查要点 |
|---|---|---|---|
| ASI-01 | **提示注入** Prompt Injection | 外部输入操纵模型行为 | 用户输入/网页内容/工具输出是否进入 system prompt？有无隔离？ |
| ASI-02 | **不安全输出处理** | 模型输出直接执行/渲染 | 输出进 shell/HTML/SQL 前有无清洗转义？ |
| ASI-03 | **训练数据投毒** | 训练/检索数据被污染 | RAG 数据源可信度？有无校验层？ |
| ASI-04 | **模型拒绝服务** | 长上下文/资源耗尽 | 上下文长度限制？并发配额？ |
| ASI-05 | **供应链漏洞** | 模型/插件/依赖被篡改 | 依赖钉死？模型来源可信？ |
| ASI-06 | **敏感信息泄露** | 训练/对话数据泄露 | 日志是否含 PII/密钥？数据最小化？ |
| ASI-07 | **不安全插件设计** | 插件权限过大 | 插件最小权限？网络/文件访问边界？ |
| ASI-08 | **过度代理** | Agent 权限超出任务所需 | 工具权限最小化？危险操作有人批准？ |
| ASI-09 | **过度依赖** | 无人工监督的自主决策 | 关键决策有无人类确认门？ |
| ASI-10 | **行为失控** | 模型行为偏离预期无监控 | 输出监控？越界检测？熔断机制？ |

## 审查方法

对每个 LLM/Agent 相关代码路径：
1. 找「外部输入 → 模型 → 执行」的完整链路
2. 对照上表逐条问，命中记「文件:行号 + ASI-XX + 风险 + 建议」
3. 可被外部利用的命中（注入/泄露/越权）→ 一律 Blocker 起步（严重度校准规则）

## 常见检查点

- `prompt` 拼接处：用户输入与指令是否混在一起（ASI-01）
- `model.generate` / `llm.invoke` 输出流向（ASI-02）
- 工具调用权限声明（ASI-08）
- 日志打印内容（ASI-06）
- 依赖版本锁定（ASI-05）
